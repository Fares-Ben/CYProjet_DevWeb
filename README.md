# CYProjet_DevWeb
# **Smart School _ Fares BEN MABROUK  - Rayan MOUAHID - Yuness SMAIL - Tom CONTI**

## Outil Informatique de traitement de données

Smart School est un site web gérant l’ensemble du matériels connectés d'un établissement scolaire et la gestion des objets via des comptes d'utilisateurs. En incluant le fichier Restore_database.sql dans le répertoire qui lui est attribué, on peut récupérer les données nécessaires.

Une fois lancé, le site permet aux visiteurs de creer un compte pour devenir des utilisateurs et gerer l'ensemble des objets connectés de l'école. Le site va aussi permettre de generer des rapports sur différentes informations des objets comme sur la consommation.

## Compatibilité système

Le programme est compatible avec les dernières versions de **Windows** et de **Ubuntu**.

## Technologies utilisées

- Langage de programmation : `HTML`, `CSS`, `JavaScript`
- Framework Backend: `React`, `Bootstrap`
- Framework Frontend: `Node.js/Express`
- Type de programmation : **modulaire**
- Logiciel utilisé : **Visual Studio Code**

## Lancement

Pour utiliser le programme, ouvrez un terminal dans le dossier `smart-platform/`, assurez-vous de placer Restore_database.sql dans votre base de données MySQL. 

Se placer dans la racine du dossier `smart-platform/backend` et executer la commande `node server.js`

Se placer dans la racine du dossier `smart-platform/frontend` et executer la commande `npm start`

## Téléchargement

- Téléchargez `./CYProjet_DevWeb.zip` vie Github et extrayez le fichier `./CYProjet_DevWeb`.
